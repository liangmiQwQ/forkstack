# gh stack

Use GitHub's own stacked PRs when the branches are pushed to the repository the PRs merge into.

1. Check that `gh auth status` succeeds. If it doesn't, ask the user to run `gh auth login`.
2. Install the extension if `gh stack` is missing: `gh extension install github/gh-stack`. Ask the user before installing.
3. Run `gh stack --help`, and `gh stack <command> --help` for each command, to learn how to build, submit and update the stack.

You are allowed to search more information on the Internet or load more skills, if you still don't know how to use this tools.
